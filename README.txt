Portfolio Website

Files included:

- assets/SaiHanMyoShane_Technical_Portfolio_SASH.pdf: Final submitted two-page professional resume and technical portfolio.

Website purpose:
- This is a broad public portfolio covering academic work, technical projects, competitions, research interests, leadership, and community activities.
- It includes relevant material connected with ICSC, SASH, AI safety, cybersecurity, mathematics, and other STEM experiences.
- ICSC and SASH are individual parts of the portfolio and are not presented as the sole purpose for creating the website.

How to use:
1. Open index.html in a browser to preview the website.
2. Upload the complete folder contents to GitHub Pages, Vercel, Netlify, or another static website host.
3. When transferring content to Google Sites, copy the text sections manually and upload the PDF and ZIP files through Google Drive.
4. Replace the Supporting Documents placeholder with the appropriate Google Drive evidence-folder link.
5. Set the Google Drive folder permission to “Anyone with the link can view.” Do not enable edit access.
6. Keep all contact information parent-managed. Do not publish phone numbers, passport details, home addresses, or private school documents.
7. Suggested wording for an application or additional-links section:
   Official Portfolio: https://sai-han-myo-shane-portfolio.vercel.app
   Supporting Documents Folder: [insert Google Drive link]
